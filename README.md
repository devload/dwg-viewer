# 도면 뷰어 1.0.0 (무료 배포판)

브라우저에서 DWG·DXF 도면을 여는 단일 HTML 뷰어입니다.
설치가 필요 없고, 도면 파일은 브라우저 안에서만 처리되며 외부로 전송되지 않습니다.

## 주요 기능

- DWG(AutoCAD R13 ~ 2018 이후 형식, AC1012 ~ AC1032)와 텍스트 DXF 열기
- 확대·이동, 창 확대, 전체 보기, 검정/흰 배경, 흑백 보기
- 레이어 켜기/끄기·단독 보기, 모델/배치 탭
- 객체 선택과 속성 표시(길이, 반지름, 면적 등)
- 객체 스냅이 붙는 거리·면적 측정
- 문자 검색, 블록 개수 집계(엑셀로 복사)

## 사용법

`도면뷰어.html`을 크롬이나 엣지로 열고, 도면 파일을 화면에 끌어다 놓습니다.
열리지 않는 DWG는 무료 ODA File Converter로 DXF(ACAD2018)로 바꾸면 대부분 열립니다.

## 직접 빌드하기

Node.js 20 이상이 필요합니다.

```
npm install
npm run build
```

결과물은 `dist/도면뷰어.html` 한 파일입니다. 이 파일 안에 DWG 해석 엔진(WebAssembly)이
gzip으로 압축되어 들어갑니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `src/scene.js` | 도면 데이터를 화면용 선·문자로 바꾸는 변환 엔진 |
| `src/app.js` | 화면 그리기, 선택, 측정, 패널 등 사용자 화면 |
| `template.html` | 화면 구조와 스타일 |
| `build.mjs` | 하나의 HTML 파일로 묶는 빌드 스크립트 |
| `LICENSE` | GNU GPL 버전 3 전문 |
| `NOTICE.md` | 사용한 오픈소스 고지 |
